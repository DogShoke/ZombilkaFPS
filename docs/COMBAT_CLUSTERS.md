# Авторские модули офисных ячеек

Текущая библиотека — `src/server/OfficeTiles.luau`. Старая CombatClusters больше не используется. Варианты выбираются целиком для фиксированных ролей сетки 5×5; позиции предметов внутри варианта всегда заданы вручную.

Поля Slots: имя модели, местный X, местный Z, угол Y, коллизия, необязательная высота основания. Подбирай связанные предметы с понятным назначением. Сохраняй внешний свободный край; не добавляй случайные шкафы между ячейками.

Обычные модули ограничены24×24 внутри ячейки36×36, масштаб мешей общий3.5. Для подъёма отдельно заданы платформа и два пандуса, всё внутри своей ячейки. Большие предметы должны иметь простую коллизию; мелкий декор её не требует.

HARD_COVER подготовлен в библиотеке, но в начальной раскладке H нет. Полное описание схемы, роли и проверок: [LEVEL_GENERATION.md](LEVEL_GENERATION.md).
